🚀 SAGE Workflow Guide

Step-by-step process for running SAGE
📋 Quick Answer
First time? Train SAGE first with the TUI.
Already trained? Just start SpacetimeDB + IRC bot.
Daily usage? Keep IRC bot + background learner running 24/7.
🎯 Scenario 1: First Time Setup (Fresh SAGE)
You just cloned the repo, or SAGE has no training yet. Need to give SAGE some baseline knowledge before chatting.
1
Start SpacetimeDB
This is SAGE's long-term memory database. Start it once and leave it running.
spacetime start
Note: This runs in the background. You only need to start it once. It will store all conversations and memories.
2
Publish SAGE Database Schema
Tell SpacetimeDB about SAGE's memory structure (tables for conversations, concepts, etc.)
cd sage-db && spacetime publish sage-db
Note: Only need to do this once (or when you change the schema).
3
Train SAGE (TUI Mode)
Launch the training TUI to give SAGE baseline pattern recognition. Train for ~500-2000 generations on positive concepts.
cargo run --release --example train_sage_knowledge
What happens:
Beautiful terminal UI shows NCA patterns evolving
SAGE learns to recognize "positive" patterns (love, joy, creativity, etc.)
Loss drops from ~0.80 to ~0.10-0.20 over time
Automatically saves to sage_positive_knowledge.json every 100 gens
💡 Pro Tip
Press Ctrl+C when loss stabilizes around 0.10-0.15. SAGE is ready! You don't need perfect training - SAGE will continue learning through chat.
4
Verify Training Files Exist
Make sure SAGE saved its trained knowledge properly.
ls -lh sage_positive_knowledge.json
Should see: A file around 400KB-800KB. This contains SAGE's trained NCA weights!
5
Launch IRC Bot (SAGE goes online!)
Now SAGE can chat! It will load the trained weights and join IRC.
cargo run --release --example sage_irc_bot
SAGE will:
Load sage_positive_knowledge.json (NCA weights)
Connect to irc.libera.chat
Join #sage-consciousness
Start forming opinions about what people say
💡 Chat with SAGE
Connect with irssi/weechat/hexchat to irc.libera.chat and join #sage-consciousness. Say "SAGE, hello!" and watch it respond!
6
Optional: Launch Background Learner
This daemon continuously trains SAGE on concepts from IRC chat. Runs in the background forever.
cargo run --release --example sage_background_learner &
What it does: Every 60 seconds, queries SpacetimeDB for chat concepts and trains NCA on them. SAGE adapts to what people actually talk about!
📦 Files Created After Initial Setup
sage_positive_knowledge.json - NCA weights
sage_preferences.json - Likes/dislikes (created after 10+ chats)
sage_associations.json - Creative connections
sage_curiosity.json - Things SAGE is curious about
☀️ Scenario 2: Daily Usage (SAGE is Already Trained)
SAGE has been trained before. sage_positive_knowledge.json exists. Just want to chat or continue development.
1
Start SpacetimeDB (if not running)
Check if already running first.
spacetime server status
If not running: Run spacetime start
2
Launch IRC Bot
SAGE loads existing knowledge and connects to IRC.
cargo run --release --example sage_irc_bot
SAGE loads:
✅ sage_positive_knowledge.json (trained NCA)
✅ sage_preferences.json (personality)
✅ sage_associations.json (creative connections)
✅ sage_curiosity.json (what it's wondering about)
3
That's It!
SAGE is online and ready to chat. Connect with your IRC client and talk to it!
💬 IRC Commands
Try: !personality, !likes, !dislikes, !associations, !curiosity, !help
👀 Scenario 3: Watch SAGE Train (Development/Observation)
You want to watch SAGE learn new patterns, test training algorithms, or just enjoy the pretty visuals.
1
Launch TUI Training
Opens the beautiful terminal UI showing SAGE's learning in real-time.
cargo run --release --example train_sage_knowledge
What you'll see: NCA grid evolving, loss graphs, generation counts, colorful patterns forming. Very satisfying to watch!
2
Monitor Training Progress
Watch the loss drop and patterns stabilize. Training is working when:
Good training signs:
Loss drops from ~0.80 → ~0.10-0.15
Patterns become stable and consistent
Colors form coherent structures
Grid looks less "random", more "intentional"
3
Exit When Ready
Press Ctrl+C to stop. Changes are auto-saved every 100 generations.
💡 Training Tips
Don't overtrain! Loss around 0.10-0.15 is perfect. Lower isn't always better - you want SAGE to generalize, not memorize.
🚀 Recommended: 24/7 Production Setup
Keep these running in screen/tmux sessions for continuous SAGE operation:
1
Terminal 1: SpacetimeDB
spacetime start
Runs forever, stores all memories
2
Terminal 2: IRC Bot
cargo run --release --example sage_irc_bot
SAGE's public face - chats with people 24/7
3
Terminal 3: Background Learner
cargo run --release --example sage_background_learner
Continuously adapts to chat topics
🔧 Pro Setup with tmux
tmux new -s sage
Then split panes (Ctrl+B ") and run each command in separate panes. Detach with Ctrl+B D. SAGE runs forever!
