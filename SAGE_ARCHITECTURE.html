🔑 Key Point: One SAGE, Many Faces

SAGE is a single unified entity (the core library) with multiple interfaces:

  • The TUI is for you to TRAIN and OBSERVE SAGE's learning
  • The IRC bot is for people to CHAT WITH SAGE and help it develop personality
  • The background learner makes SAGE ADAPT to what people talk about
  • All three programs use the same SAGE brain and share memory through files + SpacetimeDB

Think of it like: SAGE has one consciousness (core library), but can be accessed through different "windows" (TUI for training, IRC for chatting). Whatever SAGE learns in one place, it knows in all places because they all read/write the same JSON files and database!
