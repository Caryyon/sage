# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.3.x | ✅ |
| 0.2.x | ❌ |
| 0.1.x | ❌ |

## Reporting Vulnerabilities

Email: security@whatssage.ai

Please include:
- Description of vulnerability
- Steps to reproduce
- Impact assessment
- Suggested fix (if any)

## Security Features

- Ed25519 cryptographic identity
- Signed knowledge diffs
- Trust tier validation
- No external data collection
