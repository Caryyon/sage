What is SAGE?

An AI that runs on your computer — for free, forever.

SAGE is a decentralized AI that lives on your machine. No cloud, no accounts, no subscription. Just install and start chatting.

But here's the magic: every person who runs SAGE makes it smarter for everyone. Your node learns from your conversations, encodes that knowledge into compact neural patterns, and shares it across the network.

Your raw data never leaves your machine. Only anonymous, compressed knowledge patterns flow between nodes. Privacy by design.

Think of it like BitTorrent, but for intelligence.

Under the Hood

Technical Deep Dive

For the nerds. You know who you are.

🧬

NCA Grid — Your AI's Brain is a Living Neural Grid

▼
SAGE's core is a 32×32 Neural Cellular Automata grid with 22 channels per cell. Cells perceive neighbors via Sobel filters and update through tiny neural networks. This creates self-organizing, self-healing knowledge structures. Damage the grid and it regenerates — like biological tissue, but for intelligence. Knowledge isn't stored as text — it's encoded as stable NCA patterns that emerge from simple cellular rules.
🔄

Knowledge Sync — Encrypted Diffs, Not Your Conversations

▼
Nodes exchange compact NCA pattern diffs via a gossip protocol — not your raw conversations. These diffs are anonymous, compressed knowledge representations measured in kilobytes, not gigabytes. Peer discovery uses Kademlia DHT. Conflict resolution merges patterns via NCA superposition. Sync is lazy and runs in the background — never blocks your chat.
🔒

Privacy — PII Filtering, Differential Privacy, Local-Only Mode

▼
Raw data never leaves your machine. Knowledge is encoded into NCA patterns before any network sharing occurs. Built-in PII filtering strips personal information before encoding. Differential privacy adds calibrated noise to shared patterns. And if you want total isolation, local-only mode keeps everything on your machine with zero network traffic.
🔌

OpenAI Compatible — Drop-In Replacement for Any Tool

▼
SAGE exposes an OpenAI-compatible API on localhost. Set OPENAI_API_BASE=http://localhost:19176/v1 and any tool that speaks the OpenAI protocol — Continue, Cursor, Open WebUI, custom scripts — works with SAGE instantly. Zero code changes. No API key needed.
