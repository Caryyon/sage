# Tutorial 2: Running a SAGE Node

## Start Your Node
```bash
sage node start
```

## What Happens
- Your node joins the SAGE mesh network
- It discovers peers via mDNS (local) or bootstrap server (WAN)
- It shares knowledge diffs with connected peers
- It posts stats to whatssage.ai/network

## Check Status
```bash
sage node status
```

## Invite a Friend
```bash
sage node invite
# Share the invite code
```

## Stop the Node
```bash
sage node stop
```
