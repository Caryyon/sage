# Tutorial 1: Your First Chat with SAGE

## Install
```bash
curl -fsSL https://whatssage.ai/install.sh | bash
```

## Start Chatting
```bash
sage chat
```

## Ask Questions
- "What is SAGE?" → Simple query, answered by NCA
- "How does the mesh work?" → Complex query, answered by LLM
- "What is my name?" → SAGE remembers from context

## Exit
Type `exit` or press Ctrl+C.
