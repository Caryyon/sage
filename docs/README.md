## Examples
All examples are runnable with `cargo run --example NAME`:

- **simple-chat** — Basic chat with SAGE
- **custom-knowledge-source** — Ingest documents into the knowledge grid
- **node-federation** — Run a mesh node and sync with peers
- **router-tuning** — Inspect and train the query router
